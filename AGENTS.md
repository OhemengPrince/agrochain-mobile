# Auto-commit and push

After every task you complete that changes files in this repo (not after every individual edit), automatically run:

```
git add .
git commit -m "Auto-save: [brief description of what changed]"
git push
```

Replace `[brief description of what changed]` with a real, specific summary of the task just completed — not a generic placeholder. Do this without asking for confirmation; it's pre-authorized for this project. A Stop hook also runs as a safety net in case this is missed; prefer doing it yourself first so the commit message is descriptive rather than generic.
