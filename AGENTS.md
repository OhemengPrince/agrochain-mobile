# Auto-commit and push

After completing each task that changes files in this repo (not after every individual edit), automatically run:

```
git add . && git commit -m "Auto-save: <short description of what changed>" && git push
```

Replace `<short description of what changed>` with a real, specific summary of the task just completed. Do this without asking for confirmation — it's pre-authorized for this project. A Stop hook also runs as a safety net in case this is missed; prefer doing it yourself first so the commit message is descriptive rather than generic.
